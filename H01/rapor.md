# H01 – Multikopter bileşenleri

| Bileşen | Görevi |
|---|---|
| LiPo batarya | Sisteme elektrik enerjisi sağlar. Güç dağıtım kartı üzerinden esc'lere güç sağlar. |
| Kumanda alıcısı | Pilotun kumanda hareketlerini alır ve uçuş kontrolcüsüne iletir. |
| Flight Controller | İHA'nın ana beyin sistemi görevini üstlenir motorları ve diğer sensörleri kontrol eder. |
| Telemetri | Yer istasyonu ile drone arasındaki haberleşmeyi sağlar. yer istantonunda kontrolcüye , kontrolcüden yer istasyonuna veri akışı sağlar. |
| Görev Bilgisayarı | Kameradan gelen görüntüleri işler bunun yanısıra ağır işleri yapar otonom kararlar verir. Uçus kontrolcüsüne veri gönderir. |
| ESC | Bataryadan gelen DC akımı trifaz akıma çevirip motora iletir. Uçus kontrolcüsünden  veri alır. | 
| GPS | Uçus kontrolcüsüne konum bilgisini verir. |
| Motorlar | Multikopterin pervanelerini döndüren bileşenlerdir. Multikopterlerde fırçasız motorlar tercih edilir. |
